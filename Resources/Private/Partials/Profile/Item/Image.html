The image of a profile item. A content element that limits the shown fields and leaves the image out renders nothing here, placeholder included. All content elements share one settings array, so the view is an argument: the card template passes "card", and every other caller, the contacts of EXT:academic_contacts4pages included, leaves it out and gets "list". It selects the crop variant "settings.image..cropVariant". A profile without an image gets the placeholder of its gender, "settings.image.placeholder.", and the default placeholder when that one is empty or the profile has no gender. The placeholder keeps an empty alternative text: it shows nobody, and the name is the heading of the same item. Arguments: - profile: the profile whose image is rendered - imageView: "card" or "list", "list" when it is left out - settings: the plugin settings, read for "showFields", the crop variant and the placeholder Only a profile with a gender builds the key: "placeholder." with an empty last segment is no setting. The shared partial of EXT:academic_base: the image, or the placeholder for a profile without one.
