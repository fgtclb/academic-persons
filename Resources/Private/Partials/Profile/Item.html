One profile, as the list, the card, the selected profiles, the selected contracts and the contacts element of EXT:academic_contacts4pages render it. Its four parts are partials of their own, so a project changes one of them without copying this file: "Profile/Item/DetailLink", "Profile/Item/Name", "Profile/Item/Contracts" and "Profile/Item/Image". A copy of this file keeps working and simply stops profiting from them. Arguments: - profile: the profile to render - contract: one contract, when the caller has a single one to show - detailPid: the page the detail view sits on, for a caller without plugin settings; it wins over "settings.detailPid" - groupedProfiles: set by a grouped list, which puts the heading one level lower - settings: the plugin settings - data: the content element record
