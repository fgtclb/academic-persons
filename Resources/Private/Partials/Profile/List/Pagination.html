The navigation between the pages of a paginated profile list. Every link carries the visitor's choices the list is shown with - "activeListArguments" - and changes the page only. Arguments: - paginator: the paginator, for the current page - pagination: the pagination, for the pages to link - activeListArguments: the visitor's choices, as the list action assigns them
