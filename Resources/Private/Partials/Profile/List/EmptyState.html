What a plugin shows instead of the items when it found nothing. Every plugin of this extension renders it, so an override reaches all of them at once. Its class is a block of its own for that reason, as the one of "Profile/List/Items" is. Arguments: - key: the label to show, defaulting to the one about profiles. The selected contracts element passes the one about contracts - settings: the plugin settings - data: the content element record
