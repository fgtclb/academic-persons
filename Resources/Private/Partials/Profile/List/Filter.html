The visitor filters of a list element: one choice per filter the content element offers, "all" first and then the options by name, the active filter selected. It renders nothing while no filter has an option. The form posts to the filter action, which redirects to the URL of the filtered list, so it works without JavaScript, and the list it leads to is cached like any other. It keeps the view mode and the letter of the list it is on, and the filtered list starts on its first page. Arguments: - filterOptions: the options of each filter the element offers, keyed functionTypes and organisationalUnits - demand: the demand of the list, for the active filters - activeListArguments: the visitor's choices of the list - contentElementUid: keeps the ids of a list and a list-and-detail element on one page apart. Two elements of the same plugin on one page share their arguments, so a submission is checked against the options of the element that renders first.
