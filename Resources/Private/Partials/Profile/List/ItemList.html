The body of a profile list: the result count, the items - grouped or not - the pagination, and the empty state when the list found nothing. Each of those is a partial of its own: "Profile/List/ResultCount", "Profile/List/GroupHeader", "Profile/List/Items", "Profile/List/Pagination" and "Profile/List/EmptyState". The letter navigation is not one of them - the list template renders it above this partial. Arguments: the list template renders it with "{_all}", which is what it expects. - profilesToList: the profiles to show, one page of them when the list paginates - profiles: everything the list found, counted for the result count - demand: read for "groupBy" - paginator: the paginator, and "pagination" next to it - settings: read for "paginationEnabled" - data: the content element record
