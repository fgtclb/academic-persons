The grid of profile items, rendered by the list, the card, the selected profiles and the selected contracts. It carries the Bootstrap row and column classes, so a project changes the grid of all four by overriding this one file. Its semantic item-list wrapper sits outside the Bootstrap row, so component styling and grid gutters remain independent in every caller. It iterates contracts when it is given some, and profiles otherwise: the selected contracts element shows one item per selected contract, which is the one contract that item renders, while every other caller shows one item per profile with all of them. Arguments: - profiles: the profiles to render, one item each - contracts: the contracts to render instead, one item each - groupedProfiles: set by a grouped list, so the item picks the lower heading level - imageView: the view whose crop variant the item image renders, "card" from the card. Every other caller leaves it out and gets "list". - settings: the plugin settings, handed to every item - data: the content element record, handed to every item
