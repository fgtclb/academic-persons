The view mode "table": one row per profile - per contract in the selected contracts element - and one column per entry of "settings.table.columns", in that order. The site setting "plugin.tx_academicpersons.table.columns" sets them; a contract column the content element leaves out of its fields, "settings.showFields", is dropped by the action. Each cell is the partial "Profile/ViewMode/Table/Cell". A project overrides that one to add a column of its own; a column it does not know stays empty. A profile row shows the contracts the plugin settings select, as the tiles do, through "persons:contracts". A contract row shows its own contract. Arguments: those of every view mode, see "Profile/ViewMode/List". It does not take "class": that is the class of the grid, which a stylesheet of the grid targets. Nor does it read "groupedProfiles": a grouped list renders one table per group.
