One cell of the table view mode. The shipped columns are "name", "position", "organisationalUnit", "emailAddresses", "phoneNumbers" and "room"; any other column renders an empty cell. A project overrides this partial to add one. The contract columns list the value of every contract of the row, one per line. Arguments: - column: the column, an entry of "settings.table.columns" - profile: the profile of the row - contracts: the contracts of the row - settings: the plugin settings - data: the content element record {contract.position} {contract.organisationalUnit.displayText} {contract.organisationalUnit.unitName} The link target drops the spaces of the stored number and carries the site's prefix, the visible text is the stored number - as in "Profile/Contract/Field". {phoneNumber.phoneNumber} {contract.room} The name and the detail link come from the partials the tiles use, which render them unescaped; handed in as values, they are escaped once here, as the item headings do. {name}
