The public profile. Which elements render, in which column and in which order, comes from the `profile.structure` map of `Configuration/AcademicPersons/Settings.yaml`, handed in as `publicProfile`; every element is one partial below `Profile/PublicProfile/`, dispatched by `Element.html`. The `left` column is the desktop navigation, the `right` column the content; below the large breakpoint the `left` elements are rendered again directly before `subline`.
